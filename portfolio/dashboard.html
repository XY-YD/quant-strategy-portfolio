📖 策略原理：双均线交叉

双均线策略是最经典的趋势跟踪策略之一。通过计算短期和长期移动平均线（MA），当短期均线上穿长期均线（"金叉"）时买入，下穿（"死叉"）时卖出。核心思想是捕捉趋势的起始和结束。

MA_short = mean(close, N_short) # 如 MA5 MA_long = mean(close, N_long) # 如 MA15 if MA_short crosses above MA_long: BUY # 金叉信号 elif MA_short crosses below MA_long: SELL # 死叉信号
MA5/MA15 — 短周期 MA10/MA30 — 中周期 MA20/MA60 — 长周期
!
均线参数容易过拟合，需要比较不同股票和周期。夏普比率仅供参考，不代表未来收益。

📖 策略原理：海龟交易策略

海龟策略是 1980 年代理查德·丹尼斯创立的经典趋势突破系统。核心是在价格突破 N 日最高点时买入（唐奇安通道突破），使用 ATR（真实波幅）动态计算止损位和仓位大小，实现"截断亏损，让利润奔跑"。

upper = max(high, N_days) # 唐奇安通道上轨 lower = min(low, N_days) # 唐奇安通道下轨 ATR = avg(TrueRange, M_days) # 平均真实波幅 if close > upper: BUY # 突破入场 stop_loss = entry_price - 2 * ATR # 2倍ATR止损 position_size = risk_capital / ATR # ATR定仓
N=20 — 通道周期 ATR×2 — 止损倍数 1% — 单笔风险
!
趋势突破策略在震荡市场中可能频繁失效，需要结合止损纪律。ATR="市场的恐慌指数"，止损="保险绳"。

📖 策略原理：双系统海龟进阶

双系统海龟在经典海龟基础上引入两个独立突破系统：S1（短周期 20/10 日）捕捉中短期趋势，S2（长周期 55/20 日）捕捉大级别行情。两个系统独立产生信号，可以同时持仓并金字塔加仓，实现趋势的分层捕捉。

# 系统1: 短周期 (20日突破入场, 10日突破离场) S1_buy = close > max(high, 20) S1_sell = close < min(low, 10) # 系统2: 长周期 (55日突破入场, 20日突破离场) S2_buy = close > max(high, 55) S2_sell = close < min(low, 20) # 金字塔加仓: 每上涨 0.5*ATR 加仓 1 单位 if profit_per_unit >= 0.5 * ATR: add_position() # 最多加仓 4 次
S1: 20/10 日 S2: 55/20 日 加仓: 0.5×ATR 最大加仓: 4 次
!
双系统海龟(S1=20/10短线 + S2=55/20长线)含金字塔加仓和做空，风险敞口更大。经典海龟用2倍ATR止损控制每笔风险。

📖 策略原理：ML 选股策略

使用梯度提升树（Gradient Boosting）模型，基于多因子特征预测股票下一季度是否上涨。每个季度截面提取技术指标、估值因子、动量因子等特征，训练模型后对未来涨跌做二分类预测，选 Top 预测得分的股票构建多头组合。

# 季度截面选股 features = [RSI, MACD, MA_ratio, momentum, volatility, ...] labels = (next_quarter_return > 0) # 二分类标签 model = GradientBoostingClassifier() model.fit(X_train, y_train) # 每季度预测 + 选股 scores = model.predict_proba(X_test) portfolio = top_n_stocks(scores, n=10) # 选预测涨幅最大的10只

📖 策略原理：参数寻优与样本外检验

对双均线策略进行 1296 组参数的网格搜索，在样本内（2019-2023）寻找最优参数组合，然后在样本外（2024-2026）做前向测试，检验策略是否过拟合。同时计算 VaR/CVaR 风险指标和不同交易成本下的收益敏感性。

# 网格搜索 for short_ma in range(2, 20): for long_ma in range(short_ma+1, 60): result = backtest(data_in_sample, short_ma, long_ma) record(result.sharpe, result.return) # 样本外验证 best_params = select_top(params, by='sharpe') oos_result = backtest(data_out_sample, *best_params) # 比较样本内外表现差异，检查过拟合

📖 策略原理：布林带策略

���林带（Bollinger Bands）由 John Bollinger 提出，由三条线组成：中轨为 N 日移动均线(MA)，上轨和下轨分别为中轨 ± k 倍标准差。当价格触及或突破下轨时视为超卖（买入信号），触及或突破上轨时视为超买（卖出信号）。适合震荡市，单边趋势中容易产生假信号。

MA = mean(close, period) # 中轨 (20日) STD = std(close, period) # 标准差 Upper = MA + STD_mult * STD # 上轨 (2倍标准差) Lower = MA - STD_mult * STD # 下轨 if close crosses below Lower: BUY # 超卖反弹信号 elif close crosses above Upper: SELL # 超买回落信号
period=20 — 均线周期 k=2.0 — 标准差倍数
!
布林带在震荡市表现最佳，单边强趋势中会反复触发假突破信号。建议结合趋势过滤指标使用。

📖 策略原理：RSI 策略

RSI（相对强弱指标）由 Welles Wilder 提出，通过比较一定周期内上涨和下跌的平均幅度来衡量价格动量。RSI 值在 0-100 之间：低于 30 为超卖区间（买入信号），高于 70 为超买区间（卖出信号）。在震荡市中，RSI 能有效捕捉均值回归机会。

RSI = 100 - 100 / (1 + RS) RS = avg_gain / avg_loss # 14日内 avg_gain = mean(max(Δclose, 0), 14) avg_loss = mean(max(-Δclose, 0), 14) if RSI crosses above 30: BUY # 脱离超卖，反弹开始 elif RSI crosses below 70: SELL # 脱离超买，回落开始
period=14 — RSI 周期 oversold=30 — 超卖阈值 overbought=70 — 超买阈值
!
RSI 策略基于均值回归假设。在强趋势市场中，RSI 可能长时间处于超买/超卖区域而无法回归，导致踏空或亏损。

📖 策略原理：动量策略

动量策略（Momentum）基于"强者恒强"的市场惯性原理：计算 N 日价格变化率（ROC），当动量由负转正时买入（趋势确立），动量转负时卖出（趋势衰竭）。属于纯趋势跟踪策略，在单边市场中表现优异，但震荡市中容易反复止损。

Momentum = (close[t] / close[t-N] - 1) × 100% if Momentum crosses above 0: BUY # 动量转正，趋势确立 elif Momentum crosses below 0: SELL # 动量转负，趋势结束
lookback=20 — 动量计算周期
!
动量策略在趋势市表现优异，但在横盘震荡市中会产生大量假信号导致频繁交易。建议配合波动率过滤使用。
