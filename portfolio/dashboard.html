如何启动本地回测服务

  1. 打开终端，进入项目目录
  2. 安装依赖: pip install flask flask-cors tushare pandas numpy
  3. 启动服务: python backtest_server.py --port 8081
  4. 服务启动后，刷新本页面即可使用

或者直接使用命令行工具: python custom_backtest.py --code 300750 --strategy dual-ma --params 5,15
